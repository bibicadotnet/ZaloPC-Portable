# ZaloPC Portable

Phiên bản viết lại dựa theo bản của thành viên [chín hai](https://voz.vn/u/chin-hai.1704367/) trên [voz](https://voz.vn/t/zalopc-portable.1064415/)

- `update.bat` sử dụng khi lần đầu cài đặt hoặc khi cần cập nhập lên bản mới hơn
- `add_to_startup.bat` tự chạy khi khởi động Windows  
- Thêm tùy chọn `!multiple = 2` để khi gọi tới Zalo không thông báo "Zalo đang chạy"

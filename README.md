# ZaloPC Portable

Phiên bản viết lại dựa theo bản của thành viên [chín hai](https://voz.vn/u/chin-hai.1704367/) trên [voz](https://voz.vn/t/zalopc-portable.1064415/)

Phiên bản ZaloPC Portable này dữ liệu lưu trữ ở 1 vị trí riêng, khi cài lại Windows, đăng nhập lại, dữ liệu còn nên không cần đồng bộ từ điện thoại sang, có cơ hội giữ lại các dữ liệu cũ

# Cài đặt

- Download [ZaloPC.Portable.zip](https://github.com/bibicadotnet/ZaloPC-Portable/releases/download/setup/ZaloPC.Portable.zip)
- Giải nén
- Bật chạy `update.bat` để cập nhập lên bản mới nhất
- Chạy `Zalo.exe` đăng nhập, sử dụng như thông thường
- Chạy `add_to_startup.bat` để Zalo Portable tự chạy mỗi khi khởi động lại Windows
